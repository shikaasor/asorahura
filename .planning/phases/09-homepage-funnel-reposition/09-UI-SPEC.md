## Spacing Scale

Declared values (source: `src/app/globals.css` lines 3–59, Phase 6/8 canonical):

| Token | Value | Usage |
|-------|-------|-------|
| `--spacing-1` | 4px | Icon gaps, inline padding, tight grouping |
| `--spacing-2` | 8px | Compact element spacing |
| `--spacing-3` | 16px | Default element spacing, body padding |
| `--spacing-4` | 24px | Section padding, container gutters |
| `--spacing-5` | 32px | Layout gaps, card margins |
| `--spacing-6` | 48px | Major section breaks |

Exceptions: none. Do not introduce new spacing values (no `1rem`, no `5rem`, no ad-hoc `gap`) — every touched line in HeroSection, PainSection, ServicesPreview, SocialProof, Navigation, and Footer must use a `--spacing-N` token per the Phase 8 conversion rule already applied sitewide.

## Typography

Source: `src/app/globals.css` (Phase 6/8 canonical, 2-weight system only).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / subheading | `--fontSize-2` (16px) | `--fontWeight-normal` (400) | `--lineHeight-normal` (1.5) |
| Label / eyebrow | `--fontSize-1` (12px) | `--fontWeight-bold` (700) | `--lineHeight-tight` (1.1) |
| Heading (h2/h3, card titles) | `--fontSize-5`–`--fontSize-6` (pick nearest existing step used by each component today) | `--fontWeight-bold` (700) | `--lineHeight-tight` (1.1) |
| Display (h1 hero headline) | `--fontSize-7` (48px), scale down via media query on mobile — no `clamp()` | `--fontWeight-bold` (700) | `--lineHeight-tight` (1.1) |

No new weights (no 500/600/800). No `clamp()`. Copy length changes in this phase must not force a font-size change — if new hero/pain copy is longer than the old copy, wrap onto an additional line rather than shrinking the token.
