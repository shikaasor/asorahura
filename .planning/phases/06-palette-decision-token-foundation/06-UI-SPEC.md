# Phase 6 — UI Design Contract: Palette Decision + Token Foundation

> Design system infrastructure contract for the light-first token foundation. This phase establishes the complete token system (color, type, spacing, radius, shadow, transition) that Phase 7 and beyond will build on. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| `--spacing-xs` | 4px | Icon gaps, inline padding, tight grouping |
| `--spacing-sm` | 8px | Compact element spacing, input borders |
| `--spacing-md` | 16px | Default element spacing, body padding |
| `--spacing-lg` | 24px | Section padding, container gutters |
| `--spacing-xl` | 32px | Layout gaps, card margins |
| `--spacing-2xl` | 48px | Major section breaks, hero bottom padding |

**Ratio:** 1:2 compression (4 → 8 → 16 → 24 → 32 → 48). No exceptions; all breakpoints use these 6 steps.

**Implementation:** Define once in `:root` as `--spacing-*` variables; Tailwind config extends from these.

## Typography

Light-first, warm/editorial tone. Type scale follows a 1.25× ratio (major-third modular scale, standard for editorial design systems).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Small (caption) | 12px | 400 | 1.4 | Footnotes, timestamps, muted labels |
| Body | 16px | 400 | 1.6 | Default body text, prose |
| Lead | 18px | 400 | 1.6 | Article leads, intro paragraphs |
| Subtitle | 20px | 500 | 1.5 | Secondary headings, card titles |
| Heading | 24px | 600 | 1.3 | Section headings (h3, h4) |
| Large | 32px | 700 | 1.2 | Primary headings (h2) |
| Display | 48px | 700 | 1.1 | Hero/display headings (h1) |

**Font Family:** `var(--font-sans)` = `Inter, -apple-system, BlinkMacSystemFont, Segoe UI, Roboto, sans-serif` (no serif override for headings; Playfair Display removed).

**Letter Spacing:** h1–h4 retain existing `-0.02em` tracking; all other roles use browser default.

**Implementation:** Define as `--fontSize-*`, `--fontWeight-*`, `--lineHeight-*` in `:root`. No `.serif` utility class (removed).

## Color Palette

### Palette Direction Comparison

Phase 6 builds a comparison board at `/internal/palette-review` showing 3 light-first directions side-by-side on identical hero, pricing-card, and CTA-button components. All 3 directions operate within these constraints:

- **Base surface:** Warm off-white/cream range (~`#FAF7F2` ± 2–3 steps)
- **Accent:** Lightened warm gold/amber (60–70% lightness, avoiding full #FFD700 saturation)
- **Tone:** Warm/editorial (not clean/minimal SaaS) — preserves operator-to-operator credibility from brand
- **Contrast floor:** All text/background pairings ≥ 4.5:1 (body text) and ≥ 3:1 (large text) per WCAG AA

**Phase 6 Outcome (auto-selected per D-10):** Direction B (Lighter Cream + Medium Gold)

### Border Radius Scale (3 steps)

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-sm` | 4px | Small interactive elements, inputs |
| `--radius-md` | 8px | Cards, buttons, modals |
| `--radius-lg` | 12px | Large sections, hero overlays |

### Shadow Scale (3 steps)

| Token | Value | Usage |
|-------|-------|-------|
| `--shadow-sm` | `0 1px 2px rgba(31, 27, 23, 0.05)` | Subtle elevation, hover lift |
| `--shadow-md` | `0 4px 8px rgba(31, 27, 23, 0.1)` | Standard card shadow |
| `--shadow-lg` | `0 12px 24px rgba(31, 27, 23, 0.12)` | Modal/overlay shadow |

### Transition Speed (3 steps)

| Token | Value | Usage |
|-------|-------|-------|
| `--duration-fast` | 150ms | micro-interactions (hover, focus) |
| `--duration-normal` | 300ms | standard transitions (state changes) |
| `--duration-slow` | 500ms | page transitions, heavy animations |

All transitions default to `cubic-bezier(0.4, 0, 0.2, 1)` (standard ease).

## Token Naming Convention

**Semantic-scale naming** replaces existing `--bg-*` / `--gold-*` / `--text-*` structure:

```
Color:
  --surface-1, --surface-2, --surface-3, --surface-4 (background scale)
  --ink-1, --ink-2, --ink-3 (text scale)
  --accent, --accent-hover, --accent-active (accent + states)
  --success, --error, --warn (semantic states)
  --border-1, --border-2 (border scale)

Type:
  --fontSize-xs, --fontSize-sm, --fontSize-base, --fontSize-lg, --fontSize-xl, --fontSize-2xl, --fontSize-3xl
  --fontWeight-normal (400), --fontWeight-medium (500), --fontWeight-semibold (600), --fontWeight-bold (700)
  --lineHeight-tight (1.1), --lineHeight-normal (1.5), --lineHeight-relaxed (1.6)

Spacing:
  --spacing-xs (4px), --spacing-sm (8px), --spacing-md (16px), --spacing-lg (24px), --spacing-xl (32px), --spacing-2xl (48px)

Radius:
  --radius-sm (4px), --radius-md (8px), --radius-lg (12px)

Shadow:
  --shadow-sm, --shadow-md, --shadow-lg (pre-computed values above)

Transition:
  --duration-fast (150ms), --duration-normal (300ms), --duration-slow (500ms)
```

**Legacy Aliases Removed:** `--background`, `--foreground`, `--muted`, `--border` aliases are deleted. Existing stylesheets' `var()` references will break (intended; fixed Phase 8 during rollout).

## Contrast Verification Script (DESIGN-07)

**Deliverable:** `scripts/verify-contrast.js` or `scripts/verify-contrast.ts` (language TBD, recommend Node.js for CI/CD integration)

**Responsibility:** Scans all token definitions in `src/app/globals.css` and verifies every text/background pairing meets minimum contrast ratios.

### Algorithm

1. Parse `:root` CSS custom properties from `globals.css`
2. Extract color definitions (hex or rgba)
3. For each combination of `--ink-*` or semantic-text color paired with `--surface-*` or semantic-bg color:
   - Calculate perceived luminance using WCAG 2.0 formula
   - Calculate contrast ratio = (L1 + 0.05) / (L2 + 0.05)
   - Verify: body text (Ink 1–2) ≥ 4.5:1, large text (Ink 3) ≥ 3:1
   - Verify: semantic colors (Success/Error/Warn) ≥ 4.5:1 on all surfaces
4. Report all failures with: token pair, calculated ratio, required floor
5. Exit code 1 on any failure (CI/CD gate)

### Usage

```bash
npm run verify:contrast

# Expected output (all pass):
✓ Ink 1 on Surface 1: 21.0:1 (required 4.5:1)
✓ Ink 2 on Surface 1: 8.1:1 (required 4.5:1)
✓ Ink 3 on Surface 1: 4.5:1 (required 3:1)
...
All pairings pass WCAG AA.
```

### Integration

- Add `verify:contrast` script to `package.json`
- Include in pre-commit hook (optional; recommend for Phase 8+)
- Include in CI/CD pipeline before deploy
