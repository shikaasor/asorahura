| T-10-03 | Spoofing | AssessmentSectorGate "Enterprise" choice (consumed from both shells) | mitigate | Destination is the hardcoded literal `/enterprise` passed via `router.push`, never built from props, query params, or user input — no open-redirect surface |
| T-10-04 | Tampering | `/assessment?depth=deep` query param | accept | The value only selects which client component (`AssessmentShell` vs `DeepAssessmentShell`) renders via a strict `=== "deep"` string comparison; it is never interpolated into a URL, redirect target, or database query — worst case a user sees the wrong assessment depth, no privilege or data boundary crossed |
| T-10-05 | Denial of Service / Open Redirect | `src/app/assessment/deep/page.tsx` server redirect | accept | `redirect("/assessment?depth=deep")` is a fixed internal literal, not derived from any request data — standard Next.js internal redirect, no external or user-controlled destination |
