| Browser (untrusted form data) → src/app/engage/actions.ts server action | The `enterprise` and `score` form fields are attacker-controllable before submission |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-08 | Tampering | src/app/engage/actions.ts redirect decision | mitigate | The `enterprise` field is only ever compared with a strict `=== "true"` check that selects between two hardcoded literal `redirect()` targets (`https://calendly.com/asorahura` or `/engage/confirmation`) — the raw form value is never passed into `redirect()` directly, so no crafted `enterprise` value can redirect to an attacker-controlled URL (no open redirect) |
| T-10-09 | Spoofing | services/page.tsx and checkout/page.tsx outbound hrefs | mitigate | All new hrefs (`/engage?tier=...`, `/engage?enterprise=true`) are hardcoded string literals tied to a fixed, small tier-id enum defined in this same file — none are built from free-text user input |
</threat_model>
