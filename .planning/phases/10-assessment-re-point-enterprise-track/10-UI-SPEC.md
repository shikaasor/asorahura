## Interaction Patterns

### Assessment Results → Checkout (New Primary Path)

```
1. User completes assessment (quick or deep)
2. Score calculated → revenue opportunities inferred from sector + tier
3. ResultsScreen renders (unified component for both assessment types)
   - Revenue summary (gold, 48px)
   - Automation breakdown (3–4 items, bullet format)
   - CTA: "See Your Purchase Options" → /checkout
4. User routes to /checkout to purchase
   - No intermediate /engage form in primary path
   - Checkout shows selected automations + pricing tiers
5. Post-purchase: success page collects onboarding details (per PROD-07)
```

### Sector Gating UX (TBD Interaction Pattern)

**Two options (planner decides):**

**Option A: Modal/Inline Gate at Assessment Entry**
- User lands on `/assessment` (or dedicated gate page)
- Sees gate choice: "Small Business" vs. "Enterprise"
- Selects path → assesses into appropriate flow
- SMB: quick/deep assessment, revenue results, checkout
- Enterprise: redirects to `/enterprise` page (can access assessment from there if desired)

**Option B: Assessment First, Gate at Results**
- User starts assessment immediately (UX simpler, less friction)
- After scoring: results screen shows revenue for SMB path
- Secondary message: "Are you in a regulated sector? [View Enterprise Path →]" links to `/enterprise`
- Enterprise: already on website, can explore regulated verticals and `/engage`

**Research recommends Option A** (informational gate before assessment, not gatekeeping). Planner confirms in plan.

## Copy Style Guide (Phase 10)

**Numbers:**
- Revenue: `~$XXX–$YYY/mo` (range format with tilde to indicate estimate)
- Hours: `X hrs/wk` or `X hours per week` (spell out in body, abbreviate in tight UI)
- Hourly rate: `at $XX/hr` (shown in parentheses as justification)

**Tone:**
- SMB path: Fast, confident, specific ("You can save $X with this automation")
- Enterprise path: Professional, regulatory-aware ("Compliance-aware implementation")
- Never hedging: "Potential savings" or "estimated" should always include a range, not uncertainty

**Buttons:**
- Primary CTA: Always action + outcome ("See Your Purchase Options", "Get Started", "View Your Plan")
- Secondary CTA: Always action ("Learn More", "Explore Enterprise", "Discuss Your Needs")
- Destructive: Not applicable for Phase 10

## Accessibility & Responsive
