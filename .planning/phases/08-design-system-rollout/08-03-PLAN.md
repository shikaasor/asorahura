    - `background:` / `background-color:` set to `#0a0a0a` or `#04080F` (or `var(--bg-base, #04080F)`) → `var(--surface-1)`. Set to a lighter gray (`#f1f5f9`, `#f8fafc`, `#f9fafb`) → `var(--surface-2)` or `var(--surface-3)` (pick `--surface-3` if the rule is for a hover/focus state, `--surface-2` otherwise).
    - `color:` set to `#fff`/`#ffffff` (text-on-dark) → `var(--ink-1)` (dark text, since surface is flipping to light). Set to `#9ca3af`/`#6b7280`/similar mid-gray → `var(--ink-2)` (secondary) or `var(--ink-3)` (tertiary/help text — use ink-3 for the more muted/smaller-context uses). Set to `#0a0a0a`/`#1f172a`/`#374151` (dark text already) → `var(--ink-1)` or `var(--ink-2)`.
    - `border-color:` / `border:` with a hex value → `var(--border-1)` (subtle) or `var(--border-2)` (default/stronger) — use `--border-2` for card/panel outlines, `--border-1` for hairline dividers.
    - `box-shadow:` with an rgba value → nearest of `var(--shadow-1)`, `var(--shadow-2)`, `var(--shadow-3)` based on blur/spread magnitude (small offset/blur → shadow-1, medium → shadow-2, large/modal-like → shadow-3).
    - `var(--gold, #C9A060)` → `var(--accent)`; `var(--gold-light, #E0B878)` → `var(--accent-hover)`.
    - `var(--foreground)` → `var(--ink-1)`; `var(--muted)` → `var(--ink-2)`; `var(--border)` (no number suffix) → `var(--border-1)`.

    Also apply STYLE-05: any `font-weight` outside 400/700 (500, 600, 800, 900) collapses to `var(--fontWeight-normal)` or `var(--fontWeight-bold)` (pick bold for anything ≥600). Any `font-size` in px/rem/clamp() maps to the nearest of `--fontSize-1` through `--fontSize-7` (12/16/18/20/24/32/48px) — for `clamp()` responsive font-sizes, use the token nearest the clamp's max value for the base rule, and add/adjust the file's existing `@media (max-width: ...)` block to step down one token size. Any `padding`/`margin`/`gap` value maps to the nearest of `--spacing-1` through `--spacing-6` (4/8/16/24/32/48px); leave layout-only values (`max-width`, `grid-template-columns`, `z-index`) untouched.
