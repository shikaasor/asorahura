### Accent Reservation (10% of visual weight)

Accent color (`#C9A86D`) is reserved exclusively for:
1. **Primary CTA buttons:** "Join Waitlist", "View Details", "Purchase", "Schedule Demo" on catalog and detail pages
2. **Catalog card borders (selected/hover state):** Optional subtle highlight when card is hovered or featured
3. **Success indicators:** Email validation checkmark, form submission confirmation

Accent is **never** used for:
- Secondary buttons (use Ink 2 on Surface 2)
- Links (use Ink 1 with underline)
- Borders or dividers (use Border 1/2)
- Text emphasis (use Ink 1 weight increase instead)

### CRITICAL ROUTING DECISION: `/automate` Route Change

**⚠️ IMPLEMENTATION RISK — MUST BE ADDRESSED:**

The existing `/automate` route (Phase 7) currently serves offering #1 (Instagram comment-to-DM) as a detail page. In Phase 09.1:

**Impact:**
- Existing Reel links from Phase 7 point to `/automate` expecting the Instagram offering
- Existing analytics/UTM tracking may reference `/automate` for offering #1
- Old links will now land on the catalog instead of the Instagram detail page

**Required resolution (must be determined during planning):**
1. Does offering #1 need a **redirect from `/automate` to `/automate/instagram`** for backwards compatibility?
2. **Or does the catalog at `/automate` become the canonical entry point**, with old Reel links gracefully landing on the catalog?
3. How does this affect Plausible analytics event tracking (if `/automate` path changes meaning)?

**This decision affects:**
- URL routing configuration and Next.js route structure
- Redirect rules (if backwards compatibility is required)
- Analytics event tagging and historical data interpretation
- Copy/UX strategy for the catalog landing (should it mention "Offering #1 here" if Reel traffic lands there?)

3. "Writing Constitution + Content" — "The highest margin"
4. "Rate-Aware Invoice & Quote" — "The differentiator"
5. "Client Onboarding Agent" — "The expansion play"

**Card Descriptions (Body, 16px):**
